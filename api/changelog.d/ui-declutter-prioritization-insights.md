### Changed: shorter guidance text on prioritization and insights pages

- Attack paths, exposure chains, CTEM maturity, data quality and program
  health: page subtitles cut to one short sentence, the explainer under each
  ranked list no longer repeats the subtitle, and empty states say what to do
  in one line. These strings are now translated (en, vi).
- The priority-rule dry run no longer tells you to start a reclassification
  sweep from the Cycles page: saving a rule already reclassifies the matching
  findings.
- CTEM maturity no longer shows the internal "maturity aggregator" name when
  it fails to load; compensating controls drop a note about what the
  percentage "does not currently" do.
