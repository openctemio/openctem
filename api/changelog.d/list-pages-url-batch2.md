### Changed: the CI/CD, sensor fleet and EASM review lists keep their page in the URL

- The CI/CD pipelines, runs and coverage views, the sensor fleet ("All") and
  the EASM review queue keep their page and page size in the address, and
  the CI runs view keeps its verdict filter there too. A link, a reload or
  Back shows the same page. Switching the CI/CD view, the review queue tab
  or the Sensors page mode starts the new list on page 1.
