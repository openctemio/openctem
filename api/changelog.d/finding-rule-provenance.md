### Added: findings record which rules found them

- Each sighting records whether the platform's rules or the organization's own rules found the finding, and for the organization's, which scanner template at which version (migration `003136`: nullable `findings.rule_source`, `custom_template_id`, `custom_template_version`; no rewrite). The template is matched in the finding's organization only: by the template digest the sensor reports, or, without one, by the `tenant:`-prefixed rule id one template defines. A digest of one of the organization's templates counts as the organization's even from a sensor that does not mark it.
- The finding detail's Detection rule line shows "Platform rules" with the pack and version, or "Organization template" with the template's name and version and a link to it (or that it was deleted).
