### Security: the platform console is its own service, at the root of its own site

- The console is now its own web app and image, `ghcr.io/openctemio/openctem-console` (web/console in the repository), served by the gateway's console site at its root: `https://<host>:8443/` (port mode, the default) or `https://<OPENCTEM_ADMIN_HOST>/` (host mode, recommended for production). The tenant web app (`openctem-web`) contains no console page, route or API proxy, refuses to proxy `/api/v1/admin` however it is spelled, and the console contains no tenant page. There is no `/admin` path any more, and no redirect from it.
- The console sends strict headers on every response: a nonce Content-Security-Policy with `frame-ancestors 'none'`, `base-uri 'none'`, `form-action 'self'` and no third-party script (only the sign-in CAPTCHA frame), `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Resource-Policy: same-origin`, `Origin-Agent-Cluster: ?1`, `Referrer-Policy: no-referrer` and `Cache-Control: no-store`.
- The Compose stack runs it as the `console` service (`CONSOLE_IMAGE`, `CONSOLE_VERSION`, `CONSOLE_MEMORY_LIMIT`); the gateway reaches it at `OPENCTEM_CONSOLE_UPSTREAM` (default `console:3000`). `OPENCTEM_ADMIN_PLANE` and the `X-OpenCTEM-Plane` header are removed, and the web service no longer takes `ADMIN_API_URL`.
- A platform administrator who signs in on the tenant sign-in page is told to use the console instead of being sent to `/admin`.
- **Upgrade note:** open the console at the root of its site (bookmarks to `/admin/...` drop the `/admin` prefix). A platform identity provider's redirect URI becomes `<console origin>/login/callback`. Deployments other than this Compose file add the console service (the Helm chart and the Ansible kit do in their own releases).
