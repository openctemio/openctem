### Added: save a scan to start when its scope is approved
- `POST /api/v1/scans` takes `start_when_scope_approved`. When every direct target the scope gate refuses is covered by a scope entry that waits for approval, the scan is saved without a run and starts on its own, as the person who asked, once the entry comes into effect (created active, approved, self-approved or activated). Every gate runs again at that start; any other refusal still refuses the create. The response says `starts_when_scope_approved`. A wait lapses after 30 days. Migration `001701` (`scan_scope_waits`).
- New Scan offers "Create scan, start when scope is approved" when the only thing blocking its targets is a pending approval, and keeps the wizard's state when the user leaves it (for example to approve or verify) and opens it again.
