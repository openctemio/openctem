### Behaviour change: each sensor product is judged against its own release line

- The platform knows several sensor products: the scanning sensor and the Tenable.sc connector, listed in `versions.yaml` and built into the API. A sensor is compared with its own product's latest and minimum release. Before, every sensor was compared with the scanning sensor's, so a connector at v0.1.0 showed as "version unsupported". A sensor that reports no product counts as the scanning sensor. A custom sensor built on sdk-go gets no update or unsupported verdict; its compatibility is the protocol and the capabilities it advertises.
- The SDK release is informational. The SDK minimum is gone: `sdk_status` `unsupported` and the health reason `sdk_unsupported` are replaced by `advisory` and `sdk_advisory`, for SDK releases with a published security advisory (`versions.yaml` `sdk.advisories`). The Prometheus alert `SensorSdkUnsupported` is now `SensorSdkAdvisory` (`openctem_sensors_sdk{status="advisory"}`).
- `GET /sensors/stats` returns the product catalog (`products`) and `sdk_advisories` in place of `latest_version`, `min_version` and `sdk_min_version`. Sensor responses add `product`, `product_known`, `product_latest_version` and `product_min_version`. `GET /admin/operations` returns `sdk_advisories` in place of `sdk_min_version`.
- `GET /sensors/{id}/config-templates` takes `?product=` (a catalog product id) and renders that product's install snippets, pinned to its latest image. By default it renders the snippets of the product the sensor reports, or the scanning sensor's. The Tenable.sc connector has docker run and Compose snippets.

### Removed: sensor release-channel settings

- `SENSOR_LATEST_VERSION`, `SENSOR_MIN_VERSION`, `SENSOR_SDK_LATEST_VERSION` and `SENSOR_SDK_MIN_VERSION` are removed. Every version default comes from `versions.yaml`, which is built into the API. A release bump changes YAML only, never Go code.
- **Upgrade note:** the API refuses to start while one of these variables is set. Remove them from your environment or compose file. To pin the install snippets to an older release, run the matching API release. `SENSOR_IMAGE` still points the scanning sensor's snippets at a mirror.
