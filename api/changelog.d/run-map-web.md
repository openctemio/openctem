### Added: the run map on the run page

- A run's sheet shows its live map: the workflow version the run executes,
  as stages or as a graph, each step coloured by its state with why it
  waits or failed, its chunks, outputs and findings, and each dependency
  labelled with what flowed along it. It refreshes while the run is live
  and replaces the previous workflow overlay, which drew the current
  workflow instead of the run's version.
