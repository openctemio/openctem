### Added: report template help in the console

- Settings › Pentest methodology › Report templates has a searchable tag
  reference (click a tag to copy it, download the sample data as JSON), a
  choice of three starter templates and a link to the template guide.
- Picking a file to upload checks it at once and lists every problem with
  where it is and how to fix it; saving waits until the errors are fixed.
  Preview also re-checks the stored template.
