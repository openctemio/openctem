### Added: software updates in the platform console

- A banner on every console page tells platform administrators about a security release that fixes an advisory affecting the running version (always shown) or a newer release (can be hidden until the next one).
- System > Software updates shows the running and latest versions, the advisories that affect the instance, newer releases with links to their notes, where the information came from and when, the last check's outcome, and, for super administrators, the offline import of the release feed file (RFC-105).
- Organization users see nothing of it.
