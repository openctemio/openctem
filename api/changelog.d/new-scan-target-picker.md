### Changed: New Scan target picker

- New Scan, step Targets, is one picker with three tabs: Assets (search, type and criticality filters, page, range and select-all-matching selection, selected only), Groups (searchable) and Paste (each line shown as domain, wildcard, IP, CIDR, URL or host:port; repeats counted once; Clean up). A summary under it shows how many targets, what the scope check says, and the whole selection with remove buttons and the fixes for refused targets.
- Picked assets are sent by id; the API names and checks them.
