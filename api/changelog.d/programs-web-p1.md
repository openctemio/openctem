### Added: web pages for letters of authorization, program sync and testing windows

- Scoping > Scope > **Letters**: upload a signed letter of authorization (PDF, PNG or JPEG, up to 10 MB, valid for at most two years), see whether each letter is in effect or ends soon, download it, and revoke it (scope approvers). RFC-065 §13.
- A program page shows its **scope source** (pasted, the platform researcher API, or a scope file on the program domain), the last sync and its error, and a **Sync now** button. The API token is write-only. RFC-065 §14.
- New scope found by a sync is shown for review and goes into effect only when someone accepts the new terms.
- The program form takes **testing windows**, one per line (`mon-fri 09:00-17:00 Europe/Paris`). RFC-065 §12.
