### Added: RFC-078 passkeys and account security notices (proposed)

- Design for passkeys (WebAuthn) as a second factor, as the step-up proof and
  as the platform-admin console factor (replacing its separate TOTP store),
  then passwordless sign-in; and for emails on a sign-in from a new device,
  2FA enabled, passkey added or removed, and API key created. Nothing is
  built yet.
