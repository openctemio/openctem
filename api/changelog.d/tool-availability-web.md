### Changed: the Tools page shows what your sensors really have

- Settings > Scanning > Tools lists the tools your sensors report, with a status per tool: Ready, Offline only, No sensor, Outdated or Disabled. It also shows the sensors that have each tool (n/m online, with zones), their versions, the last report and the organization's on/off switch. "Show full catalog" adds every catalog tool. The install details moved into the tool detail, under "How to add this tool to a sensor". The card view is gone.
- The scan builder, the quick scan and the workflow tool pickers disable a tool no online sensor can run and say why. The sensor detail marks a tool its grant or local policy refuses. The Capabilities page says which tools are ready.
- Custom tools can set a minimum version.
