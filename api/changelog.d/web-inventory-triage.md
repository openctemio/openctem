### Added: inventory triage in the web console

- The inventory shows each asset's scope standing from the scan gate ("In scope", "Not in scope · passive only", "Excluded", …) on desktop rows and phone cards, and lists discovered assets by default (RFC-054 §15).
- New filters (scope status, found by) and views (Not in scope, Discovered, Out of scope, New since last visit).
- Bulk actions "Mark out of scope" (exclusions, exact or by rule with a preview, or "Not ours") and "Archive", each with Undo.
