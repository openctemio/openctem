### Added: Programs in the web console

- Scoping > Scope gains a **Programs** tab (shown with `attack_surface:programs:read`, so a researcher without scope access still finds it): the program list, an import page (details, rules, pasted scope or CSV, preview of what the import creates, attestation of the previewed terms) and a program page (attestation, rules, entries, program exclusions with overlaps with the organization own scope, re-import, suspend, reactivate, end).
