### Added: key facts first in the asset drawer

- The asset drawer opens with "Key facts" for the asset's class, before risk and ownership: a domain or subdomain shows what it resolves to (every address), its CNAME, hosting (ASN and organisation), HTTP server header, TLS with version, technologies with versions and its DNS records as a table; an IP its network owner, reverse DNS, location and open ports; a service its endpoint, product, TLS and HTTP response; a certificate its subject, every SAN, issuer, validity and key; a host its operating system, addresses and hardware; a repository and a cloud storage resource their own facts. It replaces the "Service facts" chip row.
- The full property list stays below as "All properties", folded until opened, with search.
- Technologies recorded as `{ name, version }` objects are shown; they used to read as "No technologies detected".
