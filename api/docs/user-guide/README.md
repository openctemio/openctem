# OpenCTEM User Guide

The user guide for people who work in the OpenCTEM web console now lives on the
documentation site: **https://docs.openctem.io/user-guide/**. It follows the
CTEM loop the console is built around, one chapter per stage, and is kept in the
[openctemio/docs](https://github.com/openctemio/docs) repository (`user-guide/`).
When a change here alters what users see or do in the console, update the
matching chapter there.

Chapters:

1. [Getting started and the dashboard](https://docs.openctem.io/user-guide/01-getting-started/)
2. [Team and access](https://docs.openctem.io/user-guide/02-team-and-access/)
3. [Scoping](https://docs.openctem.io/user-guide/03-scoping/)
4. [Discovery and the asset inventory](https://docs.openctem.io/user-guide/04-discovery/)
5. [Exposures and findings](https://docs.openctem.io/user-guide/05-exposures-and-findings/)
6. [Prioritization](https://docs.openctem.io/user-guide/06-prioritization/)
7. [Validation](https://docs.openctem.io/user-guide/07-validation/)
8. [Mobilization](https://docs.openctem.io/user-guide/08-mobilization/)
9. [Insights and reports](https://docs.openctem.io/user-guide/09-insights-and-reports/)
10. [Settings and integrations](https://docs.openctem.io/user-guide/10-settings-and-integrations/)
11. [Platform administration](https://docs.openctem.io/user-guide/11-platform-administration/)
