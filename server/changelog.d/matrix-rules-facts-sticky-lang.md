### Changed: layout matrix counts facts as content and covers every id route

- Layout matrix (test harness, `web/e2e`): a wasted row no longer counts facts. A MetaLine of label and value, a `<dl>` fact grid, a bordered fact card and an entry page's header line are content; a lone label, notice or button row is still reported. A field under a sticky or fixed action bar is no longer reported as joined to the bar's buttons. The untranslated check treats text inside an element whose `lang` differs from the page's as content, so a document published in English on a Vietnamese page needs only `lang="en"`.
- Hosted layout matrix: `web/e2e/ci/seed-matrix.sh` now adds the rows behind every id route (SBOM components, a CTEM cycle, an asset group, a pentest campaign with a finding, an own pentest template and scan workflow, an import mapping, a bug bounty program, an emerging-threat alert, a ticket mapping draft), a pending AI-application confirmation and the legal pages turned on, so it covers the same routes as a local matrix run. Fixture data only (example.com, RFC 5737).
- Docs: web/e2e/helpers/layout-matrix.ts and web/e2e/ci/seed-matrix.sh (header comments); server/docs/development/ci-cd.md (layout matrix row)
